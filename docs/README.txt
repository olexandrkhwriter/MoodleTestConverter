  Moodle Test Converter — Конвертер тестових завдань для Moodle
  Серпень 2026
═══════════════════════════════════════════════════════════════════════════

ПРИЗНАЧЕННЯ
───────────
Програма конвертує файли тестових завдань (з позначеними правильними
відповідями) у формати імпорту Moodle: GIFT, Moodle XML, Aiken.
Розроблено з урахуванням форматів розмітки, що реально використовуються
в українських університетах та коледжах.

ШВИДКИЙ СТАРТ
─────────────
  1. Розпакуйте папку MoodleTestConverter/ у зручне місце
  2. Запустіть MoodleTestConverter.exe
  3. Натисніть «Додати файли…» → оберіть файл(и) тесту
  4. Оберіть формат виводу (GIFT / Moodle XML / Aiken)
  5. Натисніть «КОНВЕРТУВАТИ» → оберіть теку для результатів
  6. Імпортуйте отриманий файл у Moodle:
     Курс → Банк питань → Імпорт → оберіть формат → Завантажити

СКЛАД ПАКЕТА
────────────
  MoodleTestConverter.exe   — головна програма (GUI + CLI)
  _internal/                — бібліотеки (НЕ видаляти!)
  docs/                     — документація (цю теку читаєте зараз)
  samples/                  — зразкові тестові файли
  tests_uni/                — 12 тестових кейсів університетських форматів
  src/                      — вихідний код (converter_core.py, GUI)

ВИМОГИ
──────
  • Windows 7/8/10/11 (64-біт)
  • Інтернет не потрібен (працює повністю офлайн)
  • Встановлення не потрібне (portable)
