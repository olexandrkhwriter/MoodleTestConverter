1. ТЕКСТОВІ ФАЙЛИ (.txt)
────────────────────────

  Загальна структура:
    [Заголовок файлу — необов'язково, ігнорується]

    1. Текст питання
    а) варіант відповіді
    б) варіант відповіді
    ...

    2. Текст питання
    ...

  Нумерація питань (усі варіанти):
    1.        1)        Запитання 1.     Питання №2.
    Завдання 3.    Q4.        №5.

  Нумерація варіантів відповідей:
    а)  б)  в)  ...   (українські літери)
    A)  B)  C)  ...   (латинські літери)
    1)  2)  3)  ...   (цифри)
    1.  2.  3.  ...   (цифри з крапкою)

  ── Способи позначення правильної відповіді ──

  ① Зірочка в кінці рядка:
      б) Леонід Кравчук *

  ② Мітка на початку рядка:
      * б) Леонід Кравчук
      ✓ б) Леонід Кравчук
      + б) Леонід Кравчук
      *В. Леонід Кравчук   ← зірочка приклеєна до літери (без пробілу)

  ③ Пари «+ / -» (типово для ключів ВНЗ):
      + а) Азот
      - б) Кисень

  ④ Приписка після тексту:
      б) Київ (правильно)
      б) Київ (вірно)
      б) Київ (правильна відповідь)

  ⑤ Markdown-виділення:
      б) **Літій**

  ⑥ Рядок-ключ одразу після варіантів:
      1. Столиця Франції:
      а) Ліон
      б) Марсель
      в) Париж
      Відповідь: В
      ──────────────
      2. Столиця Японії:
      а) Осака
      б) Токіо
      ANSWER: B
      ──────────────
      (також: «Правильна відповідь: В», «Правильна відповідь:3»,
       «Відповідь: 2» — за номером, «Ansver: 2», «Answer:B»)

  ⑦ Таблиця-ключ у кінці файлу:
      Відповіді: 1-а, 2-б, 3-в
      Ключ: 1-а; 2-б; 3-в

  ⑦а Ненумерований формат (без номерів питань):
      Текст питання ... ?
      А. варіант 1
      *В. варіант 2 (правильна)
      Г. варіант 3
      (питання відділяються порожнім рядком або розпізнаються
       автоматично за «?» / довгим реченням)

  ⑧ Формат «QuestName:» (експорт з медичних/екзаменаційних баз):
      QuestName:Текст питання
      варіант відповіді 1
      варіант відповіді 2
      варіант відповіді 3
      trueNum:3

      • Питання починається з рядка «QuestName:» (без нумерації)
      • Варіанти відповідей — прості рядки без літер та номерів
      • Правильна відповідь вказується номером варіанта:
          trueNum:3              — 3-й варіант
          Ansver:3               — те саме (допускається помилка Ansver/Anser)
          Правильна відповідь:3  — також підтримується
      • Питання відділяються порожнім рядком

  ── Спеціальні типи питань ──

  Питання «так/ні» (автовизначення):
      1. Фотосинтез відбувається у хлоропластах.
      а) Вірно *
      б) Невірно
      (також: Так/Ні, Правда/Брехня, True/False)

  Питання на відповідність (matching):
      2. Зіставте органели та їхні функції:
      а) Мітохондрія -> Синтез АТФ
      б) Рибосома -> Синтез білка
      в) Ядро -> Зберігання ДНК

  Питання з короткою відповіддю:
      3. Скільки хромосом у соматичній клітині людини?
      Відповідь: 46

2а. MICROSOFT WORD СТАРИЙ ФОРМАТ (.doc, Word 97-2003)
─────────────────────────────────────────────
  Підтримується автоматично. Для найкращої якості встановіть
  безкоштовний LibreOffice (програма знайде його сама); якщо його
  немає — використовується antiword або встановлений MS Word, а за
  їх відсутності — вбудоване витягнення тексту. У цьому разі
  форматування (жирний) може бути втрачене, тому надійніше позначати
  відповіді текстовими маркерами (*, +, «Відповідь:»).

2. MICROSOFT WORD (.docx)
──────────────────────────

  Підтримуються ВСІ текстові позначки з розділу 1, плюс:

  ① ЖИРНИЙ шрифт правильної відповіді
      (найпоширеніший спосіб у ВНЗ)

  ② ПІДКРЕСЛЕНИЙ текст відповіді

  ③ Текст, ВИДІЛЕНИЙ КОЛЬОРОМ (маркер/виділення)

  ④ ЧЕРВОНИЙ колір шрифту відповіді

  ⑤ Табличні шаблони (автоматично розпізнаються):
      ┌────┬──────────────────┬─────────────┬─────────────┬───────────┐
      │ №  │ Питання          │ Відповідь 1 │ Відповідь 2 │ Правильна │
      ├────┼──────────────────┼─────────────┼─────────────┼───────────┤
      │ 1  │ Рік заснування?  │ 482         │ 882         │ 1         │
      │ 2  │ Автор "Лісової…" │ Л. Українка │ І. Франко   │ Відповідь1│
      └────┴──────────────────┴─────────────┴─────────────┴───────────┘

  Примітка: якщо документ містить І текстові питання, І таблицю —
  програма обробляє обидва.

3. EXCEL / CSV (.xlsx, .csv)
────────────────────────────

  Структура таблиці:
    ┌──────────────┬───────────┬───────────┬───────────┬────────────┐
    │ Питання      │ Варіант 1 │ Варіант 2 │ Варіант 3 │ Правильна  │
    ├──────────────┼───────────┼───────────┼───────────┼────────────┤
    │ Скільки ...? │ 5         │ 6         │ 7         │ 3          │
    │ Вода кипить..│ Так       │ Ні        │           │ 1          │
    └──────────────┴───────────┴───────────┴───────────┴────────────┘

  У колонці «Правильна» можна вказати:
    • літеру:        А, Б, В, Г  або  A, B, C, D
    • номер:         1, 2, 3, 4
    • текст:         повний текст правильної відповіді
    • декілька:      А, В  (для питань з кількома відповідями)

  Заголовковий рядок (перший рядок) розпізнається автоматично за
  ключовими словами: Питання/Question, Варіант/Answer, Правильна/Correct,
  Тип/Type, №/No.

  Необов'язкова колонка «Тип» для явного задання типу:
    truefalse / tf / так/ні     — питання так/ні
    shortanswer / short / коротка — коротка відповідь

  Для CSV: роздільник визначається автоматично (; або , або Tab).

4. HTML (.html, .htm)
──────────────────────
  HTML-теги видаляються автоматично; далі текст обробляється
  за правилами текстових файлів (розділ 1).

5. КОДУВАННЯ
────────────
  Автоматично розпізнаються:
    • UTF-8 (з BOM та без)
    • Windows-1251 (кирилиця)
    • Windows-1252 / Latin-1

  Рекомендація: для надійності зберігайте файли у кодуванні UTF-8.

Нові варіанти розмітки (DOCX) — case28
────────────────────────────────────────────────────────
Додано підтримку ПЛОСЬКИХ (unlettered) списків відповідей у Word,
коли номери/маркери живуть у ФОРМАТУВАНні, а не в тексті:

  1. Автонумерований список Word + правильна = ЖИРНИЙ текст
  2. Автонумерований список Word + правильна = ЖИРНИЙ (інший numId)
  3. Звичайний текст + правильна = ЗІРОЧКА * на початку рядка
  4. Звичайний текст + правильна = ЖИРНИЙ текст
  5. Звичайний текст + правильна = ЖИРНИЙ (без маркерів взагалі)
  6. Автосписок Word + ЗІРОЧКА * на початку (комбінована розмітка)
  7. Автосписок Word + ЗІРОЧКА * (інший numId)

Розпізнавання: рядок із '?' трактується як питання; наступні
короткі рядки без '?' стають окремими варіантами відповідей;
правильна визначається за зірочкою (*), жирним, підкресленням,
курсивом-кольором або виділенням (highlight).
