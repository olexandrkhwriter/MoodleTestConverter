0. ВСТАНОВЛЕННЯ
─────────────────
  Запустіть MoodleTestConverter_Setup.exe → прочитайте та прийміть
  ліцензійну угоду → оберіть теку → «Встановити». Програма з'явиться
  у меню «Пуск» і на робочому столі. Деінсталяція: «Параметри →
  Програми» або Uninstall.exe у теці встановлення.
  Тиха установка (для адміністраторів): MoodleTestConverter_Setup.exe /S

  Юридична інформація (ліцензійна угода, відмова від відповідальності)
  доступна у програмі за кнопкою «ℹ️ Інформація».

1. ГРАФІЧНИЙ ІНТЕРФЕЙС (GUI) — 5 ВКЛАДОК
─────────────────────────────────────────
  Програма має п'ять вкладок:
  • «🔄 Конвертер» — конвертація файлів тестів (основна функція);
  • «👥 Списки студентів» — списки для груп Moodle (CSV/XLSX);
  • «✨ Генерація тестів (Gemini)» — AI-генерація тестів
    (потрібен API-ключ Gemini, вводиться першим полем);
  • «🌿 Розгалужені сценарії» — AI-генерація branching scenarios
    з системним промптом (усі настройки + перегляд дерева),
    працює з будь-яким LLM-провайдером (динамічний список моделей);
  • «🔗 Moodle API» — з'єднання з Moodle (перевірка токена,
    курси, надсилання файлів).

1.1. ВКЛАДКА «КОНВЕРТЕР»
───────────────────────────

  Елементи вікна:

  ┌──────────────────────────────────────────────────────────────────┐
  │ [➕ Додати файли…] [🗑 Очистити]  Формат: [▼]  Категорія: [____] │
  ├──────────────────────────────────────────────────────────────────┤
  │ Файли для конвертації (.txt .docx .xlsx .csv .html):             │
  │  ┌────────────────────────────────────────────────────────────┐  │
  │  │ test1.txt                                                   │  │
  │  │ test2.docx                                                  │  │
  │  └────────────────────────────────────────────────────────────┘  │
  ├──────────────────────────────────────────────────────────────────┤
  │ Попередній перегляд / журнал:                                    │
  │  ┌────────────────────────────────────────────────────────────┐  │
  │  │ ::Питання 1::Текст питання {                                │  │
  │  │   ~неправильна                                              │  │
  │  │   =правильна                                                │  │
  │  │ }                                                           │  │
  │  └────────────────────────────────────────────────────────────┘  │
  ├──────────────────────────────────────────────────────────────────┤
  │ [👁 Переглянути] [❓ Довідка]                  [⚙ КОНВЕРТУВАТИ]  │
  └──────────────────────────────────────────────────────────────────┘

  Покрокова робота:

  Крок 1. «Додати файли…» — оберіть один або кілька файлів тестів,
          АБО «Додати папку…» — додайте ВСЮ папку з тестами
          (рекурсивно, включно з підпапками).
          Підтримувані формати: .txt, .doc, .docx, .xlsx, .csv, .html

  Крок 2. «Формат» — оберіть вихідний формат:
          • GIFT (.txt)       — усі типи питань (рекомендовано)
          • Moodle XML (.xml) — усі типи питань, часткові бали
          • Aiken (.txt)      — лише вибір однієї відповіді

  Крок 3. «Категорія» — необов'язково. Назва категорії питань
          у банку питань Moodle (наприклад, «Історія України»).
          Якщо у файлі є рядок «name:...» (формат newTem;),
          назва теми підтягується автоматично.

  Крок 3а. «Правильних відповідей» — режим оцінювання:
          • Декілька (автовизначення з розмітки) — якщо у питанні
            позначено кілька відповідей, бали розподіляються
            рівномірно (наприклад, 33.33% × 3). [за замовчуванням]
          • Одна (лише перша позначена) — у кожному питанні
            правильною стає лише ПЕРША позначена відповідь (100%),
            решта позначених стають неправильними.

  Крок 4. «👁 Переглянути» — перегляд результату конвертації
          перед збереженням (зручно для перевірки).

  Крок 5. «⚙ КОНВЕРТУВАТИ ВСЕ» — оберіть теку, програма конвертує
          ВСІ додані файли пакетно з прогрес-баром, потім покаже журнал.
          Великі обсяги обробляються у фоновому потоці —
          програма не зависає.

  ЗАХИСТ ВІД ПОМИЛОК:
    • Файл без позначених правильних відповідей — відхиляється
      з поясненням (а не мовчки позначає перший варіант).
    • Голий список питань без варіантів — відхиляється.
    • При форматі Aiken програма попередить, скільки питань
      було пропущено (Aiken підтримує лише одну правильну відповідь).
    • Неіснуючі файли та непідтримувані формати виявляються
      до початку конвертації.

2. КОМАНДНИЙ РЯДОК (CLI)
─────────────────────────

  Синтаксис:
    MoodleTestConverter.exe <файл1> [файл2 ...] [опції]

  Опції:
    --format gift|xml|aiken   Формат виводу (за замовчуванням: gift)
    --category "НАЗВА"        Категорія питань у Moodle
    --outdir ТЕКА             Тека для результатів (за замовчуванням: .)
    --single                  Одна правильна відповідь: лише перша
                              позначена (100%), решта — дистрактори

  Приклади:
    MoodleTestConverter.exe test.txt
    MoodleTestConverter.exe test.docx --format xml --outdir results
    MoodleTestConverter.exe *.txt --format gift --category "Фізика"
    MoodleTestConverter.exe a.txt b.docx c.xlsx --format gift --outdir out

4. ІМПОРТ У MOODLE
──────────────────
  GIFT:
    Курс → Банк питань → Імпорт → Формат файлу: GIFT →
    Оберіть файл .txt → (якщо є категорія) поставте галочку
    «З категорій із файлу» → Імпортувати

  Moodle XML:
    Курс → Банк питань → Імпорт → Формат файлу: Moodle XML →
    Оберіть файл .xml → Імпортувати

  Aiken:
    Курс → Банк питань → Імпорт → Формат файлу: Aiken →
    Оберіть файл .txt → Імпортувати
    (Увага: Aiken підтримує лише питання з однією правильною відповіддю;
     питання інших типів буде пропущено)

5. НОВІ МОДУЛІ — КОРОТКІ ІНСТРУКЦІЇ
────────────────────────────────────
  Списки студентів:
    Вставте список (по одному студенту в рядок) → «Перегляд списку» →
    перевірте username/email → «Експорт CSV (користувачі)» →
    у Moodle: Адміністрування → Користувачі → Завантажити користувачів.

  Генерація тестів (мульти-LLM):
    1) Оберіть провайдера (Google Gemini, Groq, Mistral, OpenRouter,
       Cerebras — безкоштовні; OpenAI, Anthropic — платні; або власний
       OpenAI-сумісний сервер).
    2) Кнопка «Як отримати ключ» — покрокова інструкція.
    3) Введіть API-ключ → «Отримати моделі з сервера» — програма
       запитає у провайдера доступні моделі → оберіть модель зі списку.
    4) Тема, кількість, тип, складність → «Згенерувати тести» →
       «У конвертер (GIFT)» для експорту.
    Для локального Ollama/LM Studio виберіть «OpenAI-сумісний (власний
    сервер)», введіть Base URL (наприклад http://localhost:11434/v1)
    і будь-який рядок як ключ.

  Розгалужені сценарії:
    Введіть API-ключ → заповніть тему, аудиторію, рівень, цілі →
    «Згенерувати сценарій» → «Показати дерево» (ієрархія) або
    «Експорт GIFT для Moodle».

  Moodle API:
    У Moodle: Адміністрування → Сервер → Веб-сервіси → увімкнути REST,
    створити токен → введіть URL і токен → «Перевірити з'єднання».

6. ВИРІШЕННЯ ПРОБЛЕМ
─────────────────────
  Проблема: «питань не знайдено»
    → Перевірте, що питання пронумеровані (1. 2. 3. ...)
      і правильні відповіді позначені одним із підтримуваних способів.

  Проблема: кодування кирилиці (ієрогліфи замість українських літер)
    → Програма автоматично розпізнає UTF-8, UTF-8-BOM, Windows-1251.
      Якщо проблема лишається — перезбережіть файл у UTF-8.

  Проблема: антивірус блокує exe
    → Додайте папку у виключення антивіруса. PyInstaller-збірки
      іноді викликають хибні спрацювання.

  Проблема: програма не запускається
    → Переконайтесь, що папка _internal/ знаходиться поруч з exe.
      Не переміщуйте exe окремо від папки _internal/.

📦 ГЕНЕРАТОР КУРСУ — створення повного курсу Moodle (.mbz)
═══════════════════════════════════════════════════════════════

Вкладка «📦 Генератор курсу» дозволяє з пакету сирих файлів із
тестами зібрати ГОТОВИЙ курс Moodle одним файлом.

КРОК 1. Глобальні налаштування (задаються ОДИН раз на весь курс):
  • Назва курсу, префікс занять (Заняття/Тема/Тиждень/Модуль/Урок);
  • Час на тест (хв, 0 = без обмежень);
  • Кількість спроб (0 = необмежено);
  • Метод оцінювання (highest / average / last / first);
  • Прохідний бал (%);
  • Перемішування варіантів відповідей;
  • Випадкових питань у тесті (0 = усі за списком). Якщо > 0 —
    кожен тест бере цю кількість ВИПАДКОВИХ питань зі своєї
    категорії (усі питання лишаються в банку);
  • Режим перегляду (Review options): standard / strict / full.

КРОК 2. Додайте сирі файли будь-яким способом:
  • ПЕРЕТЯГНІТЬ файли або цілу папку у список (drag-and-drop);
  • кнопка «📂 Додати сирі файли…»;
  • кнопка «📁 Додати папку з файлами» (рекурсивно).
  Підтримуються: .txt .aiken .doc .docx .xlsx .csv .html .htm
  (не-txt автоматично конвертуються через ядро програми).

КРОК 3 (необов'язково). Список тем: 1 рядок = 1 заняття.
  Якщо заповнено — назви занять беруться з цього списку за
  порядком; інакше — з назв файлів.

КРОК 4. Оберіть формат виходу:
  • «Повний курс Moodle (.mbz)» — резервна копія курсу у форматі
    tar.gz (стандарт Moodle Backup), з секціями,
    тестами, банком питань і журналом оцінок.
    Імпорт: Адміністрування курсу → Відновити (Restore) → .mbz
  • «Банк питань (Moodle XML)» — ієрархічні категорії питань.
    Імпорт: Банк питань → Імпорт → Moodle XML.

КРОК 5. Натисніть «⚙ ЗГЕНЕРУВАТИ КУРС».

ДОДАТКОВО — «📤 Експорт сирих файлів…»:
  Пакетно конвертує всі додані файли (docx/doc/xlsx/csv/html) у
  нормалізований Aiken-.txt у вибрану папку. Корисно, щоб
  перевірити/відредагувати тести перед фінальною збіркою курсу.

Формат .mbz перевірено на реальному бекапі Moodle 4.5.2 (tar.gz +
.ARCHIVE_INDEX + question_bank_entries + question_instance).
Технічна специфікація формату .mbz: docs/MOODLE_MBZ_SPECIFICATION.md

🌿 РОЗГАЛУЖЕНІ СЦЕНАРІЇ — експорт H5P та JSON
═══════════════════════════════════════════════════════════════

Після генерації сценарію доступні 4 формати експорту:
  • «💾 Зберегти сценарій (.txt)» — сирий текст сценарію;
  • «💾 Експорт GIFT для Moodle» — секція MOODLE_GIFT_EXPORT;
  • «🎓 Експорт H5P (.json)» — content.json для H5P Branching
    Scenario (вузли = H5P.BranchingQuestion, кінцівки =
    H5P.AdvancedText; усі переходи nextContentId прив'язані);
  • «📄 Експорт JSON» — універсальний JSON (формат
    branching-scenario/1.0) зі структурою дерева.

Як імпортувати H5P:
  1) У Moodle: Інтерактивний вміст (H5P) → «Завантажити» →
     оберіть content.json у пакеті H5P.BranchingScenario;
  2) Або покладіть content.json у папку content/ існуючого
     .h5p-пакета бібліотеки Branching Scenario.

Кнопка «🌳 Показати дерево» відображає ієрархічну структуру
сценарію (вузли, варіанти, переходи, бали, кінцівки).
