1. GIFT (.txt)
───────────────
  Найуніверсальніший текстовий формат Moodle. Підтримує усі типи питань.

  Синтаксис, який генерує програма:

  Категорія:
    $CATEGORY: Назва категорії

  Вибір однієї відповіді:
    ::Назва::Текст питання {
      ~неправильна відповідь
      =правильна відповідь
      ~неправильна відповідь
    }

  Вибір кількох відповідей (автоматичний розподіл балів):
    ::Назва::Текст питання {
      ~%50%правильна 1
      ~%50%правильна 2
      ~неправильна
    }

  Так/Ні:
    ::Назва::Твердження {T}
    ::Назва::Твердження {F}

  Коротка відповідь:
    ::Назва::Текст питання {=відповідь1 =відповідь2}

  Відповідність (matching):
    ::Назва::Текст питання {
      =елемент1 -> відповідь1
      =елемент2 -> відповідь2
    }

  Числове:
    ::Назва::Текст питання {#42}

  Есе:
    ::Назва::Текст питання {}

  Особливості:
    • Спецсимволи (~, =, #, {, }, :) екрануються зворотним слешем
    • Нові рядки в тексті питання замінюються на \n
    • Файл зберігається у кодуванні UTF-8

2. MOODLE XML (.xml)
─────────────────────
  Нативний XML-формат Moodle. Найточніший — підтримує часткові бали
  (fraction), загальний фідбек, назви категорій.

  Структура:
    <?xml version="1.0" encoding="UTF-8"?>
    <quiz>
      <question type="category">
        <category><text>Назва категорії</text></category>
      </question>
      <question type="multichoice">
        <name><text>Назва питання</text></name>
        <questiontext format="moodle_auto_format">
          <text>Текст питання</text>
        </questiontext>
        <defaultgrade>1.0</defaultgrade>
        <single>true</single>
        <shuffleanswers>true</shuffleanswers>
        <answernumbering>abc</answernumbering>
        <answer fraction="100" format="moodle_auto_format">
          <text>Правильна</text>
        </answer>
        <answer fraction="0" format="moodle_auto_format">
          <text>Неправильна</text>
        </answer>
      </question>
      ...
    </quiz>

  Генеровані типи: multichoice, truefalse, shortanswer, matching,
  numerical, essay, description.

  Значення fraction:
    • Вибір однієї: 100 / 0
    • Вибір кількох: рівномірний розподіл (наприклад, 33.33333 × 3)

3. AIKEN (.txt)
───────────────
  Найпростіший формат — лише питання з вибором однієї відповіді.

  Структура:
    Текст питання
    A. варіант 1
    B. варіант 2
    C. варіант 3
    ANSWER: B

  Обмеження:
    • Лише тип «вибір однієї правильної відповіді»
    • Питання інших типів при конвертації в Aiken пропускаються
    • Без категорій, фідбеку, часткових балів
