Програма перевірена на 12 тестових файлах, що відтворюють реальні формати
розмітки тестових завдань, які використовуються в українських ВНЗ.

  ┌──────────────────────────┬────────────────────────────────────────────┐
  │ Файл                     │ Формат розмітки                            │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case1_star_end.txt       │ Зірочка в кінці: «б) відповідь *»          │
  │                          │ (КНЕУ, СумДУ, методички МОН)               │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case2_marker_start.txt   │ Пари «+/-»: «+ а) правильна»               │
  │                          │ «- б) неправильна» (ключі для викладачів)  │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case3_key_lines.txt      │ Рядок-ключ після кожного питання:          │
  │                          │ «Відповідь: Б», «ANSWER: C»,               │
  │                          │ «Правильна відповідь: В»                   │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case4_key_table.txt      │ Таблиця-ключ у кінці файлу:                │
  │                          │ «Ключ: 1-а; 2-б; 3-в»                      │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case5_multi.txt          │ Множинний вибір: кілька відповідей         │
  │                          │ позначено зірочками, автоматичний          │
  │                          │ розподіл балів (50%+50%, 33%+33%+33%)      │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case6_mixed_types.txt    │ Змішані типи: так/ні + matching (->) +    │
  │                          │ коротка відповідь + multichoice            │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case7_bold.docx          │ Жирний шрифт правильної відповіді          │
  │                          │ (найпоширеніший формат ВНЗ)                │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case8_underline.docx     │ Підкреслення + кольорове виділення         │
  │                          │ (маркер у Word)                            │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case9_color.docx         │ Червоний колір шрифту правильної відповіді │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case10_table.docx        │ Табличний шаблон Word:                     │
  │                          │ № │ Питання │ Відповідь 1..N │ Правильна  │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case11_markdown.txt      │ Markdown: «**Літій**»,                     │
  │                          │ «**(правильна відповідь)**»                 │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case12_numbered_answers  │ Цифрові варіанти: «1) 90°», «2) 180° *»   │
  │ .txt                     │ + «Питання №2.» + «Запитання 1.»           │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case13_questname.txt     │ Формат «QuestName:» (медичні бази):        │
  │                          │ без нумерації питань і без літер варіантів; │
  │                          │ ключі: trueNum:3 / Ansver:2 /               │
  │                          │ Правильна відповідь:2                       │
  └──────────────────────────┴────────────────────────────────────────────┘

  │ tests_uni2/ (10 додаткових кейсів — екстремальні сценарії)          │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case14_colon_formulas    │ Двокрапки та формули в тексті:             │
  │                          │ «Закон Ома: I = U/R», «2 * 3 + 4 = ?»      │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case15_multiline         │ Багаторядкові питання: текст питання       │
  │                          │ розбитий на 2-3 рядки                      │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case16_brackets          │ Відповіді з дужками та лапками:            │
  │                          │ «(оберіть одне)», «"Заповіт"»              │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case17_no_answers        │ Файл без відповідей взагалі → відхилення   │
  │                          │ (захист від дурака)                        │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case18_all_correct       │ Усі 4 відповіді позначені «*» →            │
  │                          │ multi-select з розподілом балів 25%×4      │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case19_mixed_numbering   │ Змішана нумерація питань:                  │
  │                          │ «1.», потім «2)», потім «№3.»              │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case20_comments          │ Коментарі «//» між питаннями               │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case21_questname_compact │ QuestName без порожніх рядків між блоками  │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case22_long_answers      │ Відповіді довжиною >200 символів           │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case23_special_chars     │ Спецсимволи GIFT у тексті: =, ~, #, {, }   │
  ├──────────────────────────┼────────────────────────────────────────────┤
  │ case24_newtem            │ Реальний дамп медичної бази: 23 питання,   │
  │                          │ заголовки newTem; + name: (назва теми стає  │
  │                          │ категорією Moodle), ключі trueNum:N         │
  └──────────────────────────┴────────────────────────────────────────────┘
